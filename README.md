# 萬鈞伯裘書院課表查詢（2026-2027）

學務發展部本機系統，用來查老師同班別上課時間、地點同空閒時段。資料結構對齊《成裘集》老師簡稱、班主任安排，以及星期一至五作息（一至四每堂 35 分鐘，星期五 30 分鐘）。

## 可以做咩

1. **老師時間表**：用姓名或簡稱（例如「華」「真」「ROIS」）搜尋一週課表  
2. **課堂狀態**：查某老師喺指定節次係上課定空閒，以及地點／班別  
3. **空閒老師**：列出該時段無課老師，並按代課原則排序（當日少於 7 節、任教該班、同科優先）  
4. **共同空閒**：揀一組老師，找出大家都得閒嘅節次  
5. **班別課表**：查 1A–6E 每節科目、老師同地點  
6. **調堂安排**：事假／公假多日調堂建議；IAL 一拼調；選修並行不可單獨調；調唔到畀代堂建議  
7. **代堂編配**：勾選當日請假同事，按負數結餘優先組代堂方案  

未匯入正式 Excel 前，系統會用按手冊產生嘅示範課表，方便即時試查詢。正式總表可喺「匯入 Excel」上載。

## 代堂規則

- 請假無返：每堂 −1；代堂（大堂）：每堂 +1。未能編配嘅堂，請假人仍然扣分。
- 揀代堂人：盡量唔編張敬才、呂詩恩、梁國龍、伍卓鍵、張永泰、郭鳳萍；同一星期盡量唔連續代多過兩日；其後**負數結餘優先**（病假／請假較多者先），不以科目優先。結餘相同則當日原有堂數較少者先。
- 代堂同事當日原有課堂**不可多於 6 節**。
- **不能連續代堂**（例如代完第三節就不能再代第四節）。同自己原本課堂相鄰則可以。
- 會議同課後時段不列入代堂。確認入帳後會累計結餘；同一日再確認會覆蓋當日方案。
- **匯出 PDF**：將當日方案輸出為學務「代堂調堂處理」橫向表格（日期、請假老師、代堂人、受影響科目）。

## 給同事使用（校內網站）

學務部一部電腦做主機，同一校網同事用瀏覽器打開即可（可做調堂／代堂）：

1. Windows 雙擊 `共用啟動.bat`（Mac／Linux 用 `共用啟動.command`／`共用啟動.sh`）
2. 保持黑窗開住
3. 打開側欄「**給同事**」，複製 `http://（校內IP）:43217` 貼俾同事
4. 若同事開唔到：以系統管理員執行 `開啟校內共用防火牆.bat`

同事唔使安裝 Node。手機／電腦瀏覽器都可以查課表、空閒、調堂同代堂。

## 本機啟動

需要 [Node.js 20+](https://nodejs.org)（LTS）。解壓後可雙擊 `本機啟動.bat`（Windows）或 `本機啟動.command`（Mac）。

```bash
npm install
npm run dev
```

`data/schedule.json` 已係 2026–2027 正式教師時間表。唔使每次都 `npm run seed`。

瀏覽器打開：

- http://127.0.0.1:43217
- 或本機網域 http://timetable.mkpkc.local:43217

設定本機網域（macOS / Linux）：

```bash
sudo sh -c 'echo "127.0.0.1 timetable.mkpkc.local" >> /etc/hosts'
```

Windows（以系統管理員開啟 Notepad）編輯 `C:\Windows\System32\drivers\etc\hosts`，加入：

```
127.0.0.1 timetable.mkpkc.local
```

## 匯入學務部 Excel

支援一次過上載：

- `1.0 (2026-2027) 班級總表`
- `2.0 (2026-2027) 老師總表`
- `3.0 (2026-2027) 特別室總表`
- `各班配課總表`

建議格式：工作表用班別／老師／室名；第一行星期、第一列節次；儲存格用換行或 `/` 分隔科目、簡稱、地點。配課總表可用「中華」「英真」此類科目簡稱+老師簡稱。

匯入頁亦可下載示範 Excel，對齊上述格式。
